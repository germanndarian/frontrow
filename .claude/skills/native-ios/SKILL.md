# Native iOS (apple/)

SwiftUI app generated by XcodeGen from `apple/project.yml` (Xcode 26.6, bundle prefix `com.germanndarian`). Targets:

- `Frontrow` (app): `apple/Frontrow/` with `Account App Features Models Networking Shared Theme`.
- `FrontrowWidgets` (app extension): `apple/FrontrowWidgets/`. Home and lock widgets (`HomeWidgets.swift`, `LockWidgets.swift`, `Provider.swift`) and the Live Activity (`GameLiveActivity.swift`, `GameActivityViews.swift`).
- `FrontrowUITests` (UI test bundle): `apple/FrontrowUITests/`. Scheme `Frontrow` builds all three and tests `FrontrowUITests`.

## Steps

1. Edit Swift under the right target folder. If you add, move or delete files or change `project.yml`, run `npm run native:gen` (`cd apple && xcodegen generate`), and commit the regenerated `apple/Frontrow.xcodeproj` with it.
2. Build: `npm run native:build 2>&1 | grep -E "error:|BUILD"` (iPhone 17 Pro simulator, `-quiet`).
3. Tests: `npm run native:test 2>&1 | tail -40`. For one test, run the same `xcodebuild` as in `package.json` with `-only-testing:FrontrowUITests/<Class>`.
4. `npm run native:open` opens the project in Xcode.

## Gotchas

- The app talks to the website's `/api/*` routes, not to ESPN. Keep web and native in step when a payload changes.
- The widget target compiles `FrontrowWidgets/` plus `Frontrow/Models`, `Networking` and `Theme`; the app also compiles `HomeWidgets.swift`, `LockWidgets.swift` and `WidgetPieces.swift` for its gallery. Shared code goes in those folders (see `sources` in `project.yml`).
- `apple/DerivedData/` is git-ignored. Never commit it.
- UI tests are slow and need the simulator: they are not in the five-check gate, but run `native:build` for any change in `apple/`.
- A missing simulator name fails the build: the destination is `iPhone 17 Pro`.

## Check it worked

`npm run native:build` ends with no `error:` lines, and `npm run native:test` for UI-visible changes. Say in the PR if the native tests were not run.
